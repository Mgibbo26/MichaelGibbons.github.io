NAVIGATION ADDED
----------------
- The main landing page links directly to the interactive project hub,
  Media Recon site, RevRec workflow, PDFs and PowerPoints.
- The automation-project page links back to the career page and directly to
  Media Recon, RevRec, and each existing automation case study.
- The Media Recon page links to the career page, project hub, RevRec and case studies.
- All project links are relative, so they work locally and on GitHub Pages.

HOW TO PREVIEW
--------------
1. Keep the folder structure unchanged.
2. Open index.html.
3. Test the Interactive filter and every project card.
4. In media-recon.html, test Previous, Play, Pause, Next and Fullscreen.
5. In automation-projects.html, test project filters and all four detail tabs.
6. Test the site at mobile widths, including the main-page mobile menu.

HOW TO PUBLISH WITH GITHUB PAGES
--------------------------------
1. Upload every item in this package to the repository root.
2. Keep index.html at the repository root.
3. Keep downloads, assets, case-studies and presentations beside index.html.
4. In repository Settings > Pages, deploy from the main branch and / (root).
5. Open the published site and re-test HTML, PDF and PowerPoint links.
