Allocation and decision

Every discrepancy gets a reason.

In the test workflow, matched MISR lines receive the vendor invoice number and each comparison is assigned a defined outcome. The stated tolerance is $25.00 per line.

MatchedInvoice equals MISR, or is within $25 → AP ready
HeldInvoice below MISR, or a MISR spot was not invoiced
Media Account QueryInvoice above MISR → amount sent for MISR action
Pending billingFound in Unbilled → re-check after billing
Bonus spotFound in Non-financial at $0 → no action
Bonus chargedZero-dollar bonus/makegood charged → AQ
Ghost spotFound in no billing source → AQ with vendor
Mapping requiredUnapproved vendor identity → wait for approval

Step 104 / 18

Receive: vendor emails land in Outlook

Shared mailbox + Python saver · PDFs + original email for audit

252 emails → 252 PDFs → manifest written. Finds forwarded PDFs, de-duplicates by SHA-256 and resumes after a stop.

Vendor invoices arrive in the shared mailbox and the saver preserves both the PDF and the original email for the audit trail.
Step 205 / 18

Read the PDF, then file it by its contents

Year / Month of Service / Agency / Vendor

Duplicate re-send and remittance advice → _Exceptions. Unreadable filing fields → _Unsorted.

The folder structure is driven by what is printed on the invoice, not by the email.
Steps 3–406 / 18

Classify and extract every line

Example SCTV-264913 · 5-page TV invoice · 168 lines

251 invoices + 1 remittance classified · 11,600 lines extracted · 251 / 251 roll-up checks pass.

Documents are classified, headers and line detail are extracted, and the financial roll-up is checked.
Step 507 / 18

Load three separate billing sources

MISR 17,363 rows · Non-financial 231 rows · Unbilled 57 rows

Separate sources distinguish billed financial lines, $0 bonus/makegood activity, and booked-but-not-yet-billed lines.

Keeping all three populations separate prevents false queries.
Step 608 / 18

Map names to MISR: approve once, reuse

Vendor · agency · medium · placement · email-routing crosswalks

New trading name example: suggested COASTLINE RADIO GROUP at 88%, waiting for approval.

The engine suggests mappings but does not auto-guess unapproved identities.
Step 709 / 18

The matching cascade

Same vendor + schedule/PO → exact date → ±1 day → dimension checks → placement score ≥85

Search order: MISR → Unbilled → Non-financial → nowhere = ghost spot. Every MISR line can be used once.

Strict blocking happens first, then the search widens while preserving one-to-one allocation.
